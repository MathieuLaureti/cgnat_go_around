# CGNAT go-around
There is multiple ways to go around a CGNAT, one of the options that give the most control is using a vpn tunnel from a VPS, masquarade requests received from the public VPS to the cgnat restricted connected peers (your home servers).

Getting a VPS usually isnt free, but there is a way to get a free one (with limited specs) with Oracle cloud always free plan
